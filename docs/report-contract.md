# The Report Contract

Every document an agent produces MUST follow this contract. Theo's synthesis,
the digest, and the validator (`scripts/validate_report.py`) all depend on it.

## File locations

- Analyst/researcher reports: `reports/<TICKER>/<date>-<agent>.md` (e.g. `reports/TSLA/2026-07-11-tom.md`)
- Theo's verdict: `reports/<TICKER>/<date>-verdict.md`
- Daily digest: `digest/<date>.md`

## Frontmatter (all reports)

```yaml
---
agent: tom              # tom|john|david|amy|baldy|hairy|theo
ticker: TSLA
date: 2026-07-11
stance: positive        # see tiers below; baldy is always the bull case, hairy the bear
confidence: medium      # high|medium|low (rubric below)
key_findings:           # 3-6 one-sentence findings, most important first
  - "Q2 deliveries beat production for the first time in 4 quarters"
sources:                # every dataflows call used
  - "dataflows prices history TSLA --period 6mo"
---
```

Theo's verdict adds three fields:

```yaml
financial_outlook: neutral       # from Tom/John/David/Amy evidence
engineering_health: positive     # from Baldy/Hairy evidence (production, recalls, specs)
horizon_months: 12               # 6-12; must be stated
```

## Rating tiers (decision 5.1)

Outlook language, NOT trade signals: `strong_positive | positive | neutral | negative | strong_negative`

| Tier | Meaning over the stated 6–12 month horizon |
|---|---|
| strong_positive | Evidence strongly favors improving fundamentals/position; few credible offsets |
| positive | Balance of evidence favors improvement; meaningful risks remain |
| neutral | Evidence mixed or offsetting; no directional conviction |
| negative | Balance of evidence favors deterioration |
| strong_negative | Evidence strongly favors deterioration; few credible offsets |

## Confidence rubric (decision 5.2 — computed, not vibes)

Three checks, each scored 0–2. Total 5–6 = high, 3–4 = medium, 0–2 = low.
Theo MUST print the filled rubric table in every verdict:

| Check | 0 | 1 | 2 |
|---|---|---|---|
| Data coverage | <half of expected sources returned | most returned | all returned |
| Agent agreement | analysts point opposite directions | mixed with a clear lean | broadly aligned |
| Evidence recency | key evidence >1 month old | mixed freshness | key evidence <1 week old |

## Verdict structure (Theo, decision 5.3)

1. **Header:** overall tier + confidence + horizon
2. **Two sub-scores** with 2-3 sentence justification each:
   - Financial Outlook (Tom, John, David, Amy)
   - Engineering Health (Baldy/Hairy evidence: production trends, recalls, quality, specs)
3. **The debate:** Baldy's strongest points, Hairy's strongest points — presented fairly,
   no "winner" declared (no facilitator in this firm)
4. **Theo's synthesis:** how the sub-scores combine into the overall tier, in narrative form
5. **Confidence rubric table** (filled)
6. **Disclaimer footer** (exact text below)

## Disclaimer (decision 5.4 — required on EVERY report and digest, verbatim)

> *This report is generated by an AI research project for educational purposes only.
> It is not financial, investment, or trading advice. Do your own research.*

## Validation

```
uv run python scripts/validate_report.py reports/TSLA/2026-07-11-tom.md
```

Checks frontmatter completeness, enum values, Theo's extra fields, rubric presence
in verdicts, and the disclaimer footer. Agents should validate their own report
after writing it and fix any issues before finishing.
